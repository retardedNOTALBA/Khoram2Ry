# Khoram2Ry: یک APK واحد با اتصال خودکار

یک اپ، یک نصب، یک دکمه — هسته Xray و سرویس VPN داخل خود APK است؛ نیازی به نصب اپ دوم نیست.

## با یک لمس چه اتفاقی می‌افتد

1. ساب‌لینک‌های فعال به‌صورت خودکار به‌روز می‌شوند.
2. سریع‌ترین سرور سالم پیدا و انتخاب می‌شود.
3. اتصال VPN برقرار می‌شود؛ اگر سروری جواب نداد، خودکار سراغ بعدی می‌رود.
4. اگر وسط کار قطع شود، تا ۳ بار خودش وصل مجدد می‌زند.
5. کانفیگی که از تلگرام Share کنی، مستقیم وارد اپ می‌شود.

همه این‌ها در «تنظیمات ← اتصال خودکار» قابل خاموش/روشن شدن است. هیچ سرور آماده‌ای داخل اپ نیست؛ فقط ساب‌لینک و کانفیگ خودت استفاده می‌شود.

## ساخت APK (رایگان، حدود ۵ دقیقه)

1. محتوای ZIP را در ریشه یک مخزن GitHub قرار بده (پوشه مخفی `.github` هم لازم است). هیچ کانفیگ خصوصی در مخزن نگذار.
2. تب Actions را باز کن و `Build Khoram2Ry Native APK` را اجرا کن.
3. بعد از سبز شدن، از تب **Releases** فایل `Khoram2Ry-arm64.apk` را دانلود کن (گوشی‌های ۳۲ بیتی: `arm32`).
4. نصب کن، ساب‌لینک خودت را بده، دکمه پاور را بزن.

این‌ها APK آزمایشی با امضای debug هستند، نه نسخه نهایی فروشگاهی. قبل از نصب نسخه بعدی پشتیبان بگیر. برای انتشار پایدار باید keystore شخصی و امضای release تنظیم شود؛ کلید را در مخزن عمومی نگذار.

## وضعیت تأیید

- در مرورگر فقط مدیریت کانفیگ کار می‌کند؛ مرورگر VPN دستگاه را فعال نمی‌کند.
- فایل ZIP خروجی، کد منبع و دستور ساخت است، نه APK کامپایل‌شده.
- بیلد و اتصال اندروید در محیط سازنده رابط وب اجرا نشده است. قبل از استفاده روزمره، آزمون پایین را انجام بده.
- نسخه مبنای هسته در اسکریپت ساخت به‌صورت commit ثابت مدیریت می‌شود.
- مسیر اتصال داخلی: VLESS، VMess، Trojan، Shadowsocks و JSON سازگار با Xray.
- HY2 و TUIC فعلاً فقط وارد/خارج می‌شوند؛ اتصال آن‌ها پیاده نشده است.

## معماری

- `KhoramActivity.kt`: رابط محلی، پل JavaScript، مجوز VPN، دریافت Share از اپ‌های دیگر (`khoram-import`)، انتخاب فایل و خروجی.
- `KhoramRuntime.kt`: ساخت کانفیگ با parserهای بومی v2rayNG، کنترل سرویس، تست واقعی پراکسی و شمارنده‌های واقعی هسته.
- `prepare.py`: اعمال تغییرات روی commit دقیق `5b9f24c1f0799b19f6bf43fa8d4b325df8ee137f`.
- Activity در همان process سرویس VPN اجرا می‌شود.
- ساب‌لینک فقط مستقیم با HTTPS دریافت می‌شود، بدون واسطه عمومی. خطا یا محتوای خالی، سرورهای قبلی را پاک نمی‌کند.
- در JSON کامل، ورودی SOCKS بدون احراز هویت روی 127.0.0.1 با UDP لازم است.
- DNS پیش‌فرض 1.1.1.1 فقط resolver قابل ویرایش است، نه سرور VPN.

## آزمون سریع روی گوشی

1. نصب تازه: لیست خالی باشد.
2. ساب‌لینک خودت را بده و دکمه را بزن؛ باید خودش آپدیت، تست و وصل شود.
3. مجوز VPN را یک‌بار رد کن؛ نباید «متصل» نشان دهد.
4. اینترنت را لحظه‌ای قطع/وصل کن؛ باید خودش برگردد.
5. یک کانفیگ از تلگرام Share کن؛ باید وارد اپ شود.
6. خروج IP را با سرویس مورد اعتمادت چک کن.

## مجوز

ادغام مستقل از پروژه v2rayNG تحت GPL-3.0، بدون تضمین و بدون ادعای وابستگی رسمی. هنگام انتشار APK، کد منبع متناظر و مجوز را هم منتشر کن؛ workflow آن‌ها را کنار APK می‌گذارد.
